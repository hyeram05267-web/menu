# 브릿지 커피 디지털 메뉴판

손님이 테이블의 QR 코드를 찍으면 휴대폰으로 보는 **디지털 메뉴판**이에요.
광주 북구 비엔날레에 있는 **브릿지 커피**(매일 직접 볶는 스페셜티 커피)를 위해 만들었어요.

---

## 화면 구성

| 위치 | 내용 |
|---|---|
| 맨 위 | 커피잔 그림, 가게 이름, 한 줄 소개 |
| 카테고리 버튼 | 전체 / 커피 / 논커피 / 디저트 (화면을 내려도 위에 붙어 따라와요) |
| 가운데 | 메뉴 카드 (이름, 가격, 한 줄 설명) |
| 맨 아래 | 영업시간과 '전화 걸기' 버튼 |

## 주요 기능

- **카테고리 버튼**: 버튼을 누르면 그 종류의 메뉴만 보여요. 처음에는 '전체'가 선택돼 있어요.
- **★ 시그니처 표시**: 대표 메뉴에 배지를 달고 카드를 강조해요. (지금: 아인슈페너, 흑임자 라떼)
- **오늘 품절 표시**: 품절된 메뉴는 흐리게 보이고 '오늘 품절' 배지가 붙어요.
- **전화 걸기**: 버튼을 누르면 가게로 바로 전화가 걸려요.
- **휴대폰 맞춤**: 작은 휴대폰부터 큰 휴대폰, 가로로 돌린 화면까지 깨지지 않게 맞췄어요.

## 디자인

- 수채화 정원 느낌 (물감이 번진 듯한 잎사귀와 꽃 배경)
- 대표 색상: 연두색, 주황색
- 둥근 카드와 부드러운 그림자, 넉넉한 여백
- 글꼴: 고운 돋움 (없으면 맑은 고딕)

## 파일 구성

```
메뉴판/
├── index.html               ← 메뉴판 본체 (이 파일 하나로 동작해요)
├── index_이전디자인.html     ← 예전 디자인 보관 (글래스모피즘)
├── index_멤피스디자인.html   ← 예전 디자인 보관 (멤피스)
├── CLAUDE.md                ← Claude에게 주는 작업 규칙
├── README.md                ← 지금 보고 있는 설명서
└── 자료/
    └── 기획시트.png          ← 처음 기획한 내용
```

## 메뉴 고치는 방법

메뉴 정보는 `index.html` 파일 **맨 위 '메뉴 바꾸는 곳'** 한곳에만 모여 있어요.
여기만 고치면 화면이 저절로 바뀌어요.

1. `index.html`을 마우스 오른쪽 버튼으로 눌러 **[연결 프로그램] → [메모장]** 으로 열어요.
2. `Ctrl + F`를 눌러 고칠 메뉴 이름을 찾아요.
3. 따옴표 안의 글자나 숫자만 바꿔요.
4. `Ctrl + S`로 저장하고, 인터넷 창에서 `F5`(새로 고침)를 눌러 확인해요.

메뉴 한 줄은 이렇게 생겼어요.

```js
{ 이름: "스콘", 가격: 4000, 설명: "겉은 바삭 속은 촉촉, 잼과 함께", 시그니처: "X", 품절: "X" },
```

| 하고 싶은 일 | 방법 |
|---|---|
| 가격 바꾸기 | `가격:` 뒤 숫자만 바꿔요. 쉼표와 '원'은 쓰지 않아요. (예: `4500`) |
| 품절 켜기 / 끄기 | `품절: "X"` → `품절: "O"` (다시 팔 때는 `"X"`로) |
| 시그니처 켜기 / 끄기 | `시그니처: "X"` → `시그니처: "O"` |
| 메뉴 추가 | 메뉴 한 줄을 통째로 복사해 바로 아래에 붙이고 내용을 바꿔요. |
| 메뉴 빼기 | 그 메뉴 한 줄을 통째로 지워요. |
| 종류 추가 | 종류 상자 하나를 통째로 복사해서 붙여요. 버튼도 저절로 생겨요. |

> ⚠️ 메뉴가 화면에 안 나오면 따옴표(`"`)나 줄 끝 쉼표(`,`)를 지우지 않았는지 확인하세요.
> 고치기 전에 파일 복사본을 만들어 두면 언제든 되돌릴 수 있어요.

가게 이름, 소개, 영업시간, 전화번호, 색깔도 파일 안의 ✏️ 표시가 있는 곳에서 고칠 수 있어요.
